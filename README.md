# Portafolio de Ramiro Gattone

Analista de Datos y Negocios. Sitio estático publicado con GitHub Pages: https://ramigattone77.github.io/portafolio/

## Proyectos

- **La promesa de entrega** (`proyectos/promesa-de-entrega/`): análisis de 96.203 pedidos de un marketplace de Brasil sobre cumplimiento de la fecha de entrega y su efecto en las reseñas. SQL en DuckDB y gráficos interactivos con Vega-Lite.

## Datos

El proyecto usa el [Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce), con licencia [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/). Este repositorio solo publica resultados agregados (`proyectos/promesa-de-entrega/data/`), no los datos crudos.

## Tecnología

HTML, CSS y JavaScript sin paso de compilación. Gráficos con [Vega-Lite](https://vega.github.io/vega-lite/) cargado desde jsDelivr.
